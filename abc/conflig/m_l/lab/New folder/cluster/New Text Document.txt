2. Choosing Optimal Number of Clusters (Elbow Method)
python
print("\n" + "="*70)

print("="*70)

# Calculate WCSS for different K values
wcss = []
silhouette_scores = []
K_range = range(2, 11)

for k in K_range:
    kmeans = KMeans(n_clusters=k, random_state=42, n_init=10)
    y_pred = kmeans.fit_predict(X_scaled)
    wcss.append(kmeans.inertia_)
    
    # Calculate silhouette score (requires at least 2 clusters)
    if k >= 2:
        sil_score = silhouette_score(X_scaled, y_pred)
        silhouette_scores.append(sil_score)
        print(f"K={k}: WCSS={kmeans.inertia_:.2f}, Silhouette Score={sil_score:.4f}")
    else:
        silhouette_scores.append(0)

# Find optimal K using elbow method (rate of change)
wcss_diff = np.diff(wcss)
wcss_diff_rate = np.diff(wcss_diff)
optimal_k_elbow = np.argmax(wcss_diff_rate) + 3  # +3 because diff reduces length by 2 and start from K=2

# Find optimal K using silhouette score
optimal_k_silhouette = K_range[np.argmax(silhouette_scores)]

# Visualize elbow method
fig, axes = plt.subplots(2, 2, figsize=(14, 10))

# WCSS plot
ax1 = axes[0, 0]
ax1.plot(K_range, wcss, 'bo-', linewidth=2, markersize=8)
ax1.axvline(x=optimal_k_elbow, color='red', linestyle='--', 
            label=f'Optimal K (Elbow)={optimal_k_elbow}')
ax1.set_xlabel('Number of Clusters (K)')
ax1.set_ylabel('WCSS (Inertia)')
ax1.set_title('Elbow Method for Optimal K')
ax1.legend()
ax1.grid(True, alpha=0.3)

# Silhouette score plot
ax2 = axes[0, 1]
ax2.plot(K_range, silhouette_scores, 'go-', linewidth=2, markersize=8)
ax2.axvline(x=optimal_k_silhouette, color='red', linestyle='--', 
            label=f'Optimal K (Silhouette)={optimal_k_silhouette}')
ax2.set_xlabel('Number of Clusters (K)')
ax2.set_ylabel('Silhouette Score')
ax2.set_title('Silhouette Score for Different K')
ax2.legend()
ax2.grid(True, alpha=0.3)

# Second derivative of WCSS (rate of change)
ax3 = axes[1, 0]
ax3.plot(K_range[1:], wcss_diff, 'mo-', linewidth=2, markersize=8)
ax3.axhline(y=0, color='black', linestyle='-', alpha=0.3)
ax3.set_xlabel('Number of Clusters (K)')
ax3.set_ylabel('Rate of Change (ΔWCSS)')
ax3.set_title('First Derivative of WCSS')
ax3.grid(True, alpha=0.3)

# Compare cluster assignments for different K
ax4 = axes[1, 1]
k_values_to_compare = [2, 3, 4, 5]
colors = ['red', 'blue', 'green', 'purple']

for i, k in enumerate(k_values_to_compare):
    kmeans_temp = KMeans(n_clusters=k, random_state=42, n_init=10)
    y_temp = kmeans_temp.fit_predict(X_scaled)
    
    # Use first two features for visualization
    ax4.scatter(X_scaled[y_temp == 0, 0], X_scaled[y_temp == 0, 1],

    'DBSCAN (eps=0.5)': DBSCAN(eps=0.5, min_samples=5)
}

evaluation_results = []

for name, algorithm in clustering_algorithms.items():
    # Fit and predict
    y_pred = algorithm.fit_predict(X_scaled)
    
    # Handle DBSCAN noise points (-1) for evaluation metrics
    if name.startswith('DBSCAN'):
        # Remove noise points for metric calculation
        mask = y_pred != -1
        if np.sum(mask) > 1:  # Need at least 2 points
            X_eval = X_scaled[mask]
            y_eval = y_pred[mask]
            
            # Calculate metrics (only if we have valid clusters)
            if len(set(y_eval)) > 1:
                sil_score = silhouette_score(X_eval, y_eval)
                davies_score = davies_bouldin_score(X_eval, y_eval)
                calinski_score = calinski_harabasz_score(X_eval, y_eval)
                n_clusters = len(set(y_eval))
                n_noise = np.sum(~mask)
            else:
                sil_score = davies_score = calinski_score = np.nan
                n_clusters = len(set(y_eval))
                n_noise = np.sum(~mask)
        else:
            sil_score = davies_score = calinski_score = np.nan
            n_clusters = 0
            n_noise = len(y_pred)
    else:
        # For K-Means and Hierarchical
        sil_score = silhouette_score(X_scaled, y_pred)
        davies_score = davies_bouldin_score(X_scaled, y_pred)
        calinski_score = calinski_harabasz_score(X_scaled, y_pred)
        n_clusters = len(set(y_pred))
        n_noise = 0
    
    evaluation_results.append({
        'Algorithm': name,
        'Clusters': n_clusters,
        'Noise Points': n_noise,
        'Silhouette Score': sil_score,
        'Davies-Bouldin Index': davies_score,
        'Calinski-Harabasz Score': calinski_score
    })

Summary and Practical Guidelines
python
print("\n" + "="*70)
print("CLUSTERING - SUMMARY AND PRACTICAL GUIDELINES")
print("="*70)

print("""
CLUSTERING ALGORITHMS COMPARISON:
================================

1. K-MEANS CLUSTERING:
   • Advantages:
     - Simple and fast
     - Works well with spherical clusters
     - Scales well to large datasets
   • Disadvantages:
     - Requires specifying K in advance
     - Sensitive to initial centroid selection
     - Assumes spherical clusters of similar size
   • Best for: Well-separated, spherical clusters

2. HIERARCHICAL CLUSTERING:
   • Advantages:
     - No need to specify number of clusters
     - Provides dendrogram for visualization
     - Deterministic (no random initialization)
   • Disadvantages:
     - Computationally expensive (O(n³))
     - Sensitive to noise and outliers
     - Difficult to handle large datasets
   • Best for: Small datasets, hierarchical structure exploration

3. DBSCAN CLUSTERING:
   • Advantages:
     - No need to specify number of clusters
     - Can find arbitrarily shaped clusters
     - Robust to outliers (noise detection)
   • Disadvantages:
     - Sensitive to parameter selection (eps, min_samples)
     - Struggles with varying density clusters
     - Curse of dimensionality in high dimensions
   • Best for: Non-spherical clusters, noisy data

EVALUATION METRICS INTERPRETATION:
================================
• Silhouette Score (range: -1 to 1):
  - > 0.7: Strong cluster structure
  - 0.5 - 0.7: Reasonable structure
  - 0.25 - 0.5: Weak structure
  - < 0.25: No substantial structure

• Davies-Bouldin Index (lower is better):
  - < 0.5: Excellent separation
  - 0.5 - 0.75: Good separation
  - 0.75 - 1.0: Moderate separation
  - > 1.0: Poor separation

• Calinski-Harabasz Score (higher is better):
  - Ratio of between-cluster to within-cluster variance
  - No fixed thresholds, compare across algorithms

CHOOSING THE RIGHT ALGORITHM:
============================
1. Known number of clusters + spherical data → K-Means
2. Unknown number of clusters + want hierarchy → Hierarchical
3. Non-spherical clusters + noise present → DBSCAN
4. Large dataset + approximate clusters → K-Means
5. Small dataset + want detailed analysis → Hierarchical
